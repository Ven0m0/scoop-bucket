# scoop-bucket

Personal [Scoop](https://scoop.sh) bucket.

## Install

```powershell
scoop bucket add eden https://github.com/Ven0m0/scoop-bucket
scoop install eden/eden
```

## Apps

| App | Description |
| --- | --- |
| [eden](bucket/eden.json) | Nintendo Switch emulator (amd64/x86-64-v3 clang PGO build) |
| [azaharplus](bucket/azaharplus.json) | Nintendo 3DS emulator, fork of Azahar with restored features |
